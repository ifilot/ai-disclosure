Reading a colophon

A Colophon badge records how AI contributed to a change, such as a pull request or a release, and whether a person checked the result. Here is what each part means.

How to read a colophon

Four cells score how much AI contributed to one change. The last two show whether a person reviewed it.

  1. colophonThe markLinks to a page like this one.
  2. 3DesignRequirements, architecture, plans.
  3. 4ImplementationProduction code and configuration.
  4. 4Tests & checksTests, AI code review, diagnosis.
  5. 2Comments & docsComments, docstrings, guides.
  6. FullHuman reviewFull, Partial, None, or ?.
  7. Review flagGreen, amber, or red.

The contribution scale

Each category gets one score for the whole change. The score says who produced the work, not how good it is: a 4 is not a warning and a 0 is not a merit.

The four categories

A contribution counts in every category it affected. If AI writes a function and its docstring, the function counts under Implementation and the docstring under Comments & docs.

Human review

How much AI contributed and whether a person checked it are separate questions. Any score can have Full review. Unlike the scores, the review flag is a deliberate warning: code that nobody checked is a risk, whoever wrote it.

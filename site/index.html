Scoring guide

Use 0 only when you can confirm no AI use. Count a contribution in each category it affected. Choose 4 if substantial AI output was used largely as delivered, even when it was fully reviewed.

If every score is 0, assess review of the final change itself. If an AI score is unknown, choose Full only when the review covered all in-scope work.

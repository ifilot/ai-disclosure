AI disclosure for code

Say how your code was made.

A colophon is the note at the end of a book that records how it was made. Colophon does the same for code: a short, honest record of how AI contributed to a change and whether a person checked it.

How it works

  1. 1

    Assess one change

    Pick a pull request or release and answer a few questions for each category. Most changes take a few minutes.

  2. 2

    Copy the badge

    Paste the Markdown into your README or pull request. The badge links to the rubric it was scored with.

  3. 3

    Write a short disclosure

    Say what AI contributed, what people did, and how the work was checked. The form helps you write it.

Disclosure, not judgment

The four scores describe where the work came from, not whether it is good. A 4 is not a warning and a 0 is not a merit. If AI did a remarkable job, a colophon is a place to say so.

The one thing Colophon does flag is missing review. Code that nobody checked gets a red cross, whoever wrote it.
